# 🎁 Lucky Draw Prize Wheel

행사·강의·사내 이벤트에서 쓰는 경품 추첨 원판. 로그인도 서버도 없이 브라우저 안에서 끝난다.

## 시작하기

```bash
npm install
npm run dev      # http://localhost:5173
```

빌드는 `npm run build`, 결과 확인은 `npm run preview`.

## 기능

- **경품 관리** — 이름·수량·이모지·색상을 넣고 목록에서 바로 수정한다. 수량이 0이 되면 원판에서 자동으로 빠진다.
- **경품 추천** — 회사 행사 / 교육 / 학생 이벤트 / 프리미엄 / 재미 5개 카테고리에서 골라 한 번에 담는다.
- **샘플로 시작** — 첫 방문이면 샘플 경품 6종을 한 번에 넣고 바로 돌릴 수 있다.
- **원판 추첨** — 4~5바퀴를 돌아 약 4초에 걸쳐 감속한다. 칸이 포인터를 지날 때마다 tick 소리가 난다.
- **확률 설정** — 기본은 모든 경품 균등. 켜면 경품별 확률(%)을 주며, 칸의 크기가 곧 확률이다.
- **당첨 연출** — 당첨 경품을 크게 띄우고 confetti를 2~3초 터뜨린다. 꽝은 축포 없이 표시한다.
- **당첨 기록** — 최근 당첨을 시각과 함께 남기고 CSV로 내려받을 수 있다.
- **전체화면 / 발표용 모드** — 설정 패널을 숨기고 원판만 크게 띄운다.
- **자동 저장** — 경품·수량·색상·기록·설정이 localStorage에 남아 새로고침 후에도 그대로다.

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 돌리기 (당첨 화면에서는 다시 돌리기) |
| `R` | 다시 돌리기 |
| `F` | 전체화면 |
| `ESC` | 전체화면 해제 / 당첨 화면 닫기 |

## 추첨은 어떻게 정해지나

원판이 멈춘 위치를 읽어서 당첨자를 정하지 않는다. 순서가 반대다.

1. 수량이 남은 경품만 추린다
2. `crypto.getRandomValues()` 기반 가중 추첨으로 당첨 경품을 **먼저** 정한다
3. 그 칸이 포인터 아래 오도록 최종 각도를 역산한다
4. 4~5바퀴를 더해 ease-out으로 감속시킨다

칸의 호 크기와 당첨 확률이 같은 값에서 나오므로, 확률을 40%로 준 경품은 화면에서도 정확히 144°를 차지한다.
